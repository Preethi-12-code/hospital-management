# MediCare Hospital Web Application

A modern, responsive, and feature-complete healthcare web application built with React, TypeScript, Vite, and Tailwind CSS.

## 🚀 Quick Start Guide

### 1. Extract and Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```

### 3. Build for Production Deployment (e.g. Zoho Catalyst / AppSail)
```bash
npm run build
```

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## 📦 Deploying to Zoho Catalyst
1. Run `npm run build` to generate the production `dist` folder.
2. Initialize Catalyst CLI: `catalyst init`
3. Select **Web Client** and set `./dist` as your source directory.
4. Deploy using `catalyst deploy`.
